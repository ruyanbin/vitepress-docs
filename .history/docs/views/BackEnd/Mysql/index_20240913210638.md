# Mysqs

## DDL
1. 创建表
```sql
CREATE TABLE `user` ( shurt id int(11) NOT NULL AUTO_INCREMENT,) comment '用户表';
```

```
CREATE TABLE  表明 ( 属性1 数据类型1, 属性2 数据类型2, ...) comment '注释';
```

| 属性名 | 数据类型 | 默认值 | 是否为空 | 注释 |
| :----: | :------: | :----: | :------: | :--: |
| primary key | int(11) | NULL | NOT NULL | 主键 |
| unique key | varchar(255) | NULL | NOT NULL | 唯一索引 |
| index | varchar(255) | NULL | NOT NULL | 普通索引 |
| auto_increment | int(11) | NULL | NOT NULL | 自增索引 |
| default | varchar(255) | NULL | NOT NULL | 默认值 |
| comment | varchar(255) | NULL | NOT NULL | 注释 |
| not null | varchar(255) | NULL | NOT NULL| |

2. 删除表

```sql

DROP TABLE 表名;

```

3. 修改表名
   
 ```sql
 ALTER TABLE 表名 RENAME TO 新表名;
 ```

4. 修改表结构
```添加列
ALTER TABLE 表名 ADD 列名 数据类型;
ALTER TABLE 表名 ADD 列名 数据类型 默认值;
ALTER TABLE 表名 ADD 列名 数据类型 默认值 索引;
ALTER TABLE 表名 ADD 列名 数据类型 默认值 索引 NOT NULL;
ALTER TABLE 表名 ADD 列名 数据类型 默认值 索引 NOT NULL COMMENT 注释;
ALTER TABLE 表名 ADD 列名 数据类型 默认值 索引 NOT NULL COMMENT 注释 AFTER 某列名;
```

5. 删除列
```
ALTER TABLE 表名 DROP COLUMN 列名;
ALTER TABLE 表名 DROP COLUMN 列名, DROP COLUMN 列名;
ALTER TABLE 表名 DROP COLUMN 列名, DROP COLUMN 列名, DROP COLUMN 列名;
ALTER TABLE 表名 DROP COLUMN 列名, DROP COLUMN 列名, DROP COLUMN 列名, DROP COLUMN 列名;
ALTER TABLE 表名 DROP COLUMN 列名, DROP COLUMN 列名, DROP COLUMN 列名, DROP COLUMN 列名, DROP COLUMN 列名;
```

6. 修改列名
  
```
ALTER TABLE 表名 CHANGE 旧列名 新列名 数据类型;
ALTER TABLE 表名 CHANGE 旧列名 新列名 数据类型 默认值;
ALTER TABLE 表名 CHANGE 旧列名 新列名 数据类型 默认值 索引;
```
7. 修改列属性
```
ALTER TABLE 表名 MODIFY 列名 数据类型;
ALTER TABLE 表名 MODIFY 列名 数据类型 默认值;
ALTER TABLE 表名 MODIFY 列名 数据类型 默认值 索引;
ALTER TABLE 表名 MODIFY 列名 数据类型 默认值 索引 NOT NULL;
```
8. 添加外键
```
ALTER TABLE 表名 ADD CONSTRAINT 外键名 FOREIGN KEY (外键列名) REFERENCES 外键表名(外键表列名);
```
9. 删除外键

```
ALTER TABLE 表名 DROP FOREIGN KEY 外键名;
```

- 添加数据
```
<!--单个添加 -->
insert into 表名(列名1,列名2,列名3) values(值1,值2,值3);
<!---批量添加 -->
insert into 表名(列名1,列名2,列名3) values(值1,值2,值3),(值1,值2,值3),(值1,值2,值3);
<!---批量添加2 -->
insert into 表名 values(值1,值2,值3),(值1,值2,值3),(值1,值2,值3);
```
- 删除数据

```
delete from 表名 where 条件;
truncate 表名;
delete from 表名;
delete from 表名 where id > 5;
delete from 表名 where id < 5;
delete from 表名 where id < 5 limit 5;
```

- 更新数据
```
update 表名 set 列名1=值1,列名2=值2,列名3=值3 where 条件;
update 表名 set 列名1=值1,列名2=值2,列名3=值3 where id > 5;
```
