### 4. list
#### 1. 列表
1. 列表是写在方括号[]之间、用逗号分隔开的元素列表
2. 列表可以包含不同类型的元素
3. 列表是可变的，可以添加、删除或修改元素
4. 列表可以通过索引访问元素，索引从0开始 当索引为负数时，索引从列表末尾开始计算 例如，-1表示最后一个元素，-2表示倒数第二个元素  当索引超出列表范围时，会抛出IndexError异常
5. 列表可以通过切片访问元素，切片的语法是[start:end:step]
#### 2. 列表的方法

|方法名|描述|
|:---:|:---:|
|append()|在列表末尾添加新的对象|
|count()|统计某个元素在列表中出现的次数|
|extend()|在列表末尾一次性追加另一个序列中的多个值（用新列表扩展原来的列表）|
|index()|从列表中找出某个值第一个匹配项的索引位置|
|pop()|移除列表中的一个元素（默认最后一个元素），并且返回该元素的值|
|insert()|在列表指定位置插入新元素|
|remove()|移除列表中某个值的第一个匹配项|
|reverse()|反向列表中元素|
|sort()|对原列表进行排序|
|clear()|清空列表|
|copy()|复制列表|

```
className=["张三","李四","王五"]# 创建一个列表
className.append("赵六") # 在列表末尾添加新的对象
print(className) # 输出：['张三', '李四', '王五', '赵六']

className.count("张三") # 统计某个元素在列表中出现的次数
print(className) # 输出：1

className.extend(["钱七","孙八"]) # 在列表末尾一次性追加另一个序列中的多个值（用新列表扩展原来的列表）
print(className) # 输出：['张三', '李四', '王五', '赵六', '钱七', '孙八']

className.index("李四") # 从列表中找出某个值第一个匹配项的索引位置
print(className) # 输出：1
className.pop() # 移除列表中的一个元素（默认最后一个元素），并且返回该元素的值
print(className) # 输出：钱七                                                                                                                                                                                                                                                                

className.insert(1,"周九") # 在列表指定位置插入新元素
print(className) # 输出：['张三', '周九', '李四', '王五', '赵六', '钱七']

className.remove("李四") # 移除列表中某个值的第一个匹配项
print(className) # 输出：['张三', '周九', '王五', '赵六', '钱七']
className.reverse() # 反向列表中元素
print(className) # 输出：['钱七', '赵六', '王五', '周九', '张三']

className.sort() # 对原列表进行排序
print(className) # 输出：['钱七', '张三', '王五', '赵六', '周九']

className.clear() # 清空列表

```

### dict
1. 字典是一种可变容器模型，可以存储任意类型对象
2. 字典的每个键值(key=>value)对用冒号(:)分割，每个对之间用逗号(,)分割，整个字典包括在花括号({})中
3. 键必须是唯一的，但值则不必
4. 字典的键必须为不可变对象，如字符串、数字、元组，但值可以是任何类型
::: tip
查找和插入的速度极快，不会随着key的增加而增加；
需要占用大量的内存，内存浪费多。
而list相反：

查找和插入的时间随着元素的增加而增加；

占用空间小，浪费内存很少。
所以，dict是用空间来换取时间的一种方法。
:::

#### dict的方法
|方法名|描述|
|:---:|:---:|
|clear()|删除字典内所有元素|
|copy()|返回一个字典的浅复制|
|fromkeys()|创建一个新字典，以序列seq中元素做字典的键，val为字典所有键对应的初始值|
|get(key, default=None)|返回指定键的值，如果键不存在，返回default值|
|items()|以列表返回可遍历的(键, 值) 元组数组|
|keys()|以列表返回一个字典所有的键|
|pop(key[,default])|删除字典给定键 key 所对应的值，返回值为被删除的值。key值必须给出。 否则，返回default值|
|popitem()|随机返回并删除字典中的一对键和值(一般删除末尾对)|
|setdefault(key, default=None)|和get()类似, 但如果键不存在于字典中，将会添加键并将值设为default|
|update(dict2)|把字典dict2的键/值对更新到dict里|
|values()|以列表返回字典中的所有值|

```
class Dict(dict):
    def __init__(self, **kw):
        super().__init__(**kw)

    def __getattr__(self, key):
        try:
            return self[key]
        except KeyError:
            raise AttributeError(r"'Dict' object has no attribute '%s'" % key)

    def __setattr__(self, key, value):
        self[key] = value
        return value
    
d = Dict(a=1, b=2)
print(d.a) # 1
print(d.b) # 2
```

### set
1. 集合是一个无序的不重复元素序列
2. 基本功能是进行成员关系测试和删除重复元素
3. 可以使用大括号{}或者set()函数创建集合
4. 创建一个空集合必须用set()而不是{}，因为{}是用来创建一个空字典
5. 集合中的元素必须是不可变对象，如字符串、数字、元组，但值可以是任何类型

|方法名|描述|
|:---:|:---:|
|add()|添加元素到集合中|
|update()|给集合添加元素|
|remove()|删除集合中的元素|
|discard()|删除集合中的元素|
|pop()|随机删除集合中的元素|
|clear()|清空集合|
|intersection()|返回两个或更多集合的交集|
|union()|返回两个集合的并集|
|difference()|返回多个集合的差集|
|symmetric_difference()|返回两个集合中不重复的元素集合|
|issubset()|判断集合是否是另一个集合的子集|
|issuperset()|判断集合是否是另一个集合的超集|
|isdisjoint()|判断两个集合是否没有交集|
|copy()|返回一个集合的浅复制|

```
class Set(set):
    def __init__(self, *args, **kw):
        super().__init__(*args, **kw)

    def __getattr__(self, key):
        try:
            return self[key]
        except KeyError:
            raise AttributeError(r"'Set' object has no attribute '%s'" % key)

    def __setattr__(self, key, value):
        self[key] = value
        return value

s = Set(a=1, b=2)
print(s.a) # 1
print(s.b) # 2
```
### set 与 dict 区别
::: tip
set 是一个无序的不重复元素序列
dict 是一个无序的键值对序列
set和dict的唯一区别仅在于没有存储对应的value，但是，set的原理和dict一样，所以，同样不可以放入可变对象，因为无法判断两个可变对象是否相等，也就无法保证set内部“不会有重复元素”。
:::

### 3. 递归函数

::: danger
使用递归函数需要注意防止栈溢出。在计算机中，函数调用是通过栈（stack）这种数据结构实现的，每当进入一个函数调用，栈就会加一层栈帧，每当函数返回，栈就会减一层栈帧。由于栈的大小不是无限的，所以，递归调用的次数过多，会导致栈溢出。
解决递归调用栈溢出的方法是通过尾递归优化，事实上尾递归和循环的效果是一样的，所以，把循环看成是一种特殊的尾递归函数也是可以的
尾递归是指，在函数返回的时候，调用自身本身，并且，return语句不能包含表达式。这样，编译器或者解释器就可以把尾递归做优化，使递归本身无论调用多少次，都只占用一个栈帧，不会出现栈溢出的情况
:::
```
# 修改前
def fact(n):
    if n==1:
        return 1
    return n * fact(n - 1)
# 修改后
def fact(n):
    return fact_iter(n, 1)
def fact_iter(num, product):
    if num == 1:
        return product
    return fact_iter(num - 1, num * product)
```
::: 小结
使用递归函数的优点是逻辑简单清晰，缺点是过深的调用会导致栈溢出。

针对尾递归优化的语言可以通过尾递归防止栈溢出。尾递归事实上和循环是等价的，没有循环语句的编程语言只能通过尾递归实现循环。

Python标准的解释器没有针对尾递归做优化，任何递归函数都存在栈溢出的问题。
:::
