# python 基础

## 0. 简介
::: tip
python 是一种解释型、面向对象、动态数据类型的高级程序设计语言。

python 由 Guido van Rossum 在1989年发明，第一个公开发行版发行于1991年。
python 可以应用于众多领域，如：人工智能、数据分析、Web开发、游戏开发等。

python 是一种简单易学、功能强大、可扩展性强、可移植性好的语言
python 的语法简单，代码可读性高，并且支持多线程，因此，python 在开发Web应用、数据处理、游戏开发、人工智能、机器学习、大数据分析、数据可视化、自动化测试、爬虫等应用中都得到了很好的应用。
python 是一种动态类型语言，这意味着变量的类型可以在程序运行时动态地改变。
python 是一种面向对象的语言，这意味着它支持面向对象编程的所有特性，如封装、继承、多态等。
python 是一种解释型语言，这意味着它不需要编译，而是在运行时解释代码。
:::
## 1. 安装

```
brew install python

brew install python3
```
## 2. 卸载
```
brew uninstall python
```

## 3. 查看版本
```
python --version
```

## 4. 查看安装路径
```

```
