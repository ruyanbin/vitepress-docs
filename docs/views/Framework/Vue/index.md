# vue 学习

## 介绍

```
vue 是一套用于构建用户界面的渐进式框架。它的核心是响应式数据绑定和组件化开发。
```

## 安装

```
npm install vue
```

## 创建 vue3 项目

```
pnpm create vitejs
npm create vitejs
```

## 基础语法

```
1. 绑定数据 {{}}
2. 指令 v-if v-else v-else-if
3. 指令 v-for
4. 指令 v-on
5. 指令 v-bind
6. 指令 v-model
7. 组件化开发
8. 自定义组件
9. 组件通信
10. 插槽
11. 指令
12. 插件
13. 混入
14. 过渡
15. 动画
```
